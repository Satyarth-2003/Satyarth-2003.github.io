## Overview

A modern, high-performance personal portfolio built for **Satyarth Prakash Srivastava** (AI Engineer at Adda Education / Adda247), showcasing production GenAI pipelines, agentic architectures, multimodal voice & vision systems, and deep learning engineering.

Built with **Next.js (App Router)**, **React 19**, **TypeScript**, **Tailwind CSS**, and **React Three Fiber (3D retro terminal hero)**.

## Key Features

- **Interactive 3D Hero Canvas**: Device-aware WebGL 3D rendering with lazy evaluation and fallback posters for low-power devices.
- **Single Source of Truth**: Completely typed, centralized data layer in `src/content/site.ts` powering all pages, projects, and structured JSON-LD schemas.
- **Production Projects & Case Studies**:
  - **Interview Bar**: RAG-Powered multimodal interview simulator (LangChain, OpenAI, OpenCV, MediaPipe, 95% STT accuracy).
  - **Conversational Voice AI Agent**: Low-latency voice reasoning operating under 300ms latency via duplex WebSockets.
  - **ScriptIQ & Broadcast Automation**: LLM-driven educational script automation saving ₹60+ Lakhs and reducing setup times from 30m to 2-5s across 200+ channels.
  - **CascadeGen**: Multi-modal generative diffusion models.
  - **DeepDetect**: Real-time fraud analytics and detection dashboards.
- **Research & Technical Breakdowns**: Parallel agentic audit architectures for 326,000+ audio streams under strict rate and cost constraints.
- **Interactive Command Menu (Cmd+K)**: Instant fuzzy navigation across pages, projects, credentials, and actions.
- **Interactive Curriculum Vitae**: Clean, responsive web resume display with direct PDF download.
- **SEO & Accessibility Baseline**: Fully responsive, keyboard-navigable, prefers-reduced-motion compatible, JSON-LD Person schema.

## Running Locally

```bash
# Install dependencies
npm install

# Start development server
npm run dev
```

Run type checking and production build:

```bash
npm run typecheck
npm run build
```
